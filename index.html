پنل چه می‌کند؟

پنل qa-panel ابزار ساخت «سوال چهارگزینه‌ای به سبک تراویا» از متن‌های دانشی است. متن حدوداً ۱۰۰۰ واژه‌ای (یا کل فایل بانک دانش) را می‌دهید؛ پنل متن را روی مرز <!-- SECTION -->ها یا مرز حدود ۱۰۰۰ واژه تکه می‌کند، هر تکه را با پرامپت آماده (همراه نمونه‌سوال‌های واقعی) به مدل زبانی می‌فرستد و سوال‌ها را جمع، یکتاسازی و رندر می‌کند.

راه‌اندازی مدل

  1. در تب «تولید سوال»، نشانی پایه‌ی یک API سازگار با OpenAI را وارد کنید؛ مثل https://api.openai.com/v1 یا https://api.z.ai/api/paas/v4.
  2. کلید API و نام مدل را بنویسید (مثل glm-4.5-air یا gpt-4o-mini).
  3. «شروع ساخت سوال» را بزنید. پیشرفت هر تکه جداگانه نمایش داده می‌شود و خرابیِ یک تکه بقیه را متوقف نمی‌کند.

کلید API فقط در localStorage همین مرورگر نگه داشته می‌شود و فقط به همان نشانی که خودتان وارد کرده‌اید فرستاده می‌شود. اگر نشانی درست را در مرورگر باز کرده باشید و درخواست به CORS بخورد، از پراکسی سازگار با مرورگر استفاده کنید یا فایل را روی یک دامنه‌ی مجاز اجرا کنید.

خروجی‌ها

  • JSON — آرایه‌ی سوال‌ها با question، options، answerIndex، explanation و topic؛ مناسب استفاده‌ی برنامه‌ای.
  • برگه‌ی آزمون (Markdown) — صورت سوال با گزینه‌های الف تا د + پاسخ‌نامه‌ی جدا در انتهای فایل.
