# پنل پرسش و پاسخ — qa-panel

پنل تک‌فایلی (HTML خالص، بدون بیلد) برای **ساخت سوال چهارگزینه‌ای به سبک تراویا از متن‌های دانشی**.

## تب‌ها

| تب | کار |
| --- | --- |
| **تولید سوال** | متن حدوداً ۱٬۰۰۰ واژه‌ای (یا کل فایل بانک) را می‌گیرد، آن را خودکار تکه می‌کند و با پرامپت آماده — همراه نمونه‌سوال‌های واقعی — از هر تکه چند سوال چهارگزینه‌ای می‌سازد |
| **درخواست‌های دسته‌ای** | هر خط یک درخواست آزاد (مثلاً «۲۰۰ تا اسم دانشمند مشهور ایرانی و جهانی رو برگردون»)؛ خط‌ها دونه‌دونه به مدل می‌روند، پاسخ‌ها جمع و موارد تکراری حذف می‌شوند و خروجی MD می‌گیرید |
| **بانک دانش** | مرور ۳۱۷ بخش گنجینه‌ی ایران‌شناسی (`data/iranology-quiz-bank.md`) و ارسال هر بخش یا کل یک موضوع به تب تولید سوال |
| **راهنما** | راه‌اندازی API، قواعد خروجی و توضیح بانک دانش |

## اجرا

هیچ نصب و بیلدی لازم نیست:

- فایل `index.html` را در مرورگر باز کنید، **یا**
- مخزن را کلون کنید و به‌عنوان صفحه‌ی استاتیک میزبانی کنید (مثلاً GitHub Pages — فایل `data/` هم به‌همراهش بارگیری می‌شود)، **یا**
- `python3 -m http.server` و رفتن به `http://localhost:8000`

## تنظیم مدل زبانی

پنل با هر API سازگار با OpenAI کار می‌کند. در تب «تولید سوال»:

1. **نشانی پایه**: مثل `https://api.openai.com/v1` یا `https://api.z.ai/api/paas/v4`
2. **کلید API**: فقط در `localStorage` همین مرورگر ذخیره می‌شود و فقط به همان نشانی فرستاده می‌شود
3. **نام مدل**: مثل `gpt-4o-mini` یا `glm-4.5-air`

خرابیِ هر تکه بقیه را متوقف نمی‌کند؛ هر تکه به‌صورت جداگانه وضعیت دارد و می‌توانید روند را متوقف کنید.

## پرامپت سازنده‌ی سوال

پرامپت پیش‌فرض (قابل ویرایش در تب تولید سوال) شامل:

- قواعد سوال‌سازی سبک تراویا: ۴ گزینه، یک پاسخ درست، گزینه‌های غلط باورپذیر، سبک‌های متنوع، سختی مخلوط، ممنوعیت «همه‌ی موارد»، پخش شدن جای پاسخ درست
- خروجی سختگیرانه: فقط آرایه‌ی JSON با `question`، `options`، `answerIndex`، `explanation`، `topic`
- **۱۲ نمونه‌سوال واقعی و راستی‌آزمایی‌شده** از محتوای ایران‌شناسی (نوروز و اعتدال بهاری، فرش پازیریک، چای کاشف‌السلطنه، عدد پیِ جمشید کاشانی، خوارزمی، مریم میرزاخانی، چوگان، ارگ بم، گنبد قابوس، تاق کسری، یلدا) به‌عنوان الگوی سبک

## تب «درخواست‌های دسته‌ای»

برای برداشت فهرست‌های بزرگ از مدل:

- **هر خط از کادر، یک درخواست کامل است** — هر خطی که خودتان بخواهید؛ مثلاً `۲۰۰ تا اسم دانشمند مشهور ایرانی و جهانی رو برگردون`
- پنل خط‌ها را **دونه‌دونه** به همان API تب «تولید سوال» می‌فرستد (با دکمه‌ی توقف و نوار پیشرفت)
- پاسخ هر درخواست به‌شکل فهرست تک‌خطی گرفته می‌شود؛ شماره، گلوله، مقدمه و سرستونِ گروه‌بندی خودکار پاک‌سازی می‌شود
- موارد با **نرمال‌سازی فارسی** (ی/ك، اعراب، نیم‌فاصله، علائم) مقایسه و **تکراری‌ها حذف** می‌شوند
- گزینه‌ی **«تکرار هر درخواست»** (۱ تا ۱۰): هر تکرار با دمای ۰٫۹ دوباره اجرا می‌شود تا مدل موارد تازه‌تری بدهد؛ فقط موارد جدید اضافه می‌شوند
- نتایج در `localStorage` می‌مانند و بین اجراها ادامه پیدا می‌کنند؛ خروجی‌ها: **فایل MD** (فهرست کامل + تفکیک بر پایه‌ی هر درخواست) و **کپی همه**

## بانک دانش ایران‌شناسی

`data/iranology-quiz-bank.md` — یک فایل بزرگِ آماده‌ی مصرف:

- **۳۱۷ بخش دانشی در ۱۰ موضوع**؛ مجموع حدود ۱۳۶ هزار واژه
- موضوع‌ها: ایران باستان و پیشااسلامی، تاریخ و ایران‌شناسی، بناها و یادمان‌ها، شهرهای ایران، فرهنگ و سنت‌ها و آیین‌ها، ادبیات فارسی، قهرمانان و حماسه، دانشمندان ایران، سینما، ورزش
- هر بخش زیر ۱٬۰۰۰ واژه و میان نشانه‌های ماشینی `<!-- SECTION ... -->` محصور است؛ پنل همین نشانه‌ها را برای تکه‌کردن به‌کار می‌برد
- بخش‌های راهنمای متنیِ مخزن مبدأ (روش استفاده و فهرست منابع) حذف شده‌اند تا فقط محتوای دانشی بماند
- منبع: مخزن [`jaberkh123/iran-history-iranology`](https://github.com/jaberkh123/iran-history-iranology) — دانشنامه‌ی تاریخ و ایران‌شناسی ایران

## خروجی‌ها

- **JSON**: آرایه‌ی سوال‌ها برای مصرف برنامه‌ای
- **برگه‌ی آزمون Markdown**: صورت سوال با گزینه‌های الف تا د + پاسخ‌نامه‌ی جداگانه در انتها

## ساختار مخزن

| مسیر | توضیح |
| --- | --- |
| `index.html` | کل پنل — تک‌فایل، بدون وابستگی بیلد |
| `data/iranology-quiz-bank.md` | بانک بزرگ دانش برای ورودی تب تولید سوال |
| `data/quiz-bank-stats.json` | آمار ماشینی بانک |

## نکته‌های امنیتی

- کلید API هرگز در کد یا لاگ پنل ذخیره نمی‌شود؛ فقط در مرورگرِ خودتان.
- اگر پنل را از `file://` باز کنید، بارگیری خودکار بانک ناموفق است — از دکمه‌ی «بارگذاری فایل بانک» استفاده کنید یا سرور محلی بالا بیاورید.
